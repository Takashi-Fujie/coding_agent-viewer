# SPEC-COST — 価格表とコスト計算（基本仕様書）

担当 Issue: #3（Claude）・#30（Codex モデル対応）

## ゴール

セッションログのトークン使用量から**推定**コストを算出する。キャッシュの読み書き（TTL 5分 / 1時間で単価が異なる）まで区別して計算する。

## できること

- モデル別・レコード別の推定コストを出す（input / output / cache read / cache write 5m / cache write 1h の内訳つき）
- 単価は `server/pricing.json` に外出しされており、**ユーザーが編集できる**
- 価格表に無いモデルは 0 円と黙って表示せず、**未知モデルとして警告する**
- Sonnet 5 の導入価格のような**期間限定単価**、Opus 5 fast mode のような**倍額単価**を正しく適用する
- OpenAI（Codex）モデルの単価に対応する（#30）。cached input の割引率がモデルごとに異なるため、**モデル単位で cached input 単価を指定できる**（未指定なら従来どおり input 単価 × 倍率で導出）。単価の出典は Anthropic / OpenAI の 2 本立てで表示する

## 表示上の約束

- 金額は常に「**推定**」と明示し、単価の出典を併記する
- 実測でコストの約 94% がキャッシュ由来だったため、**キャッシュ内訳を必ず表示する**（input / output だけの表示は実態を大きく取り違える）

## オーナー確認方法

`npm run report`（Issue #4 で導入）の集計値を確認する。参考値（Issue #3 時点）: 15 ファイル / 131.9MB に対する推定合計 $1,071.00、未知モデルは `<synthetic>` のみ（12 件・警告表示）。

単価・データモデル・受け入れ基準は [docs/design/COST.md](../design/COST.md)。
